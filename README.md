# 我的工作台

本机自用的个人工作生活工作台网页应用。只在这台电脑的浏览器中运行，不登录、不联网、不上云，数据保存在本机文件中。

## 启动方式

1. 确认电脑已安装 Python 3（本机已装 3.13）。
2. 双击 `启动工作台.bat`。
3. 脚本会启动本机小服务并自动打开浏览器进入首页；关闭命令行窗口即退出服务。

- 服务只监听 `127.0.0.1`，不对外暴露，不访问任何外部网络地址。
- 默认端口 `8765`；若端口被占用，启动窗口会给出提示，关闭占用程序后重试即可。

## 数据存放

- 数据目录：`data/`，每个板块一个 JSON 文件（见 PRD.md 第 7.2 节）。
- 刷新页面、关闭浏览器、重启电脑后数据均保留；清理浏览器缓存不影响数据文件。
- 所有写入采用临时文件替换的原子方式；若某个 JSON 文件损坏，启动时会自动备份为 `.bak` 并重建空结构。

## 备份与恢复

- **导出**：进入「数据设置」页，点击「导出备份」，下载一个带日期的 JSON 文件，包含全部板块数据。
- **恢复**：在「数据设置」页选择备份文件，先查看各板块条目概览，确认后覆盖恢复；导入失败不会破坏现有数据。
- **清空**：可按板块单独清空，操作前有二次确认。

## 目录结构

```
工作台APP/
├── 启动工作台.bat      # 双击启动
├── server.py          # Python 本机小服务（静态托管 + /api 接口）
├── storage.py         # 本地 JSON 数据层
├── data/              # 运行时生成的数据文件
├── web/               # 前端页面与脚本
├── tests/             # 自动化测试
├── PRD.md             # 产品需求文档
└── README.md
```

## 运行测试

在项目目录下执行：

```
python -m unittest discover -s tests -v
```

每个开发阶段对应一个测试文件（`test_stage0.py` ~ `test_stage6.py`）。

## 第一版范围

包含：首页总览、今日计划、自媒体、开发工作、咨询工作、健身计划、饮食计划、游戏娱乐、数据设置。

第一版**不包含**：登录与多用户、云同步与部署、第三方平台对接、图片附件上传、统计图表与热量计算、系统提醒与日历同步、跨板块自动关联、皮肤切换、多人协作、拖拽排序。详见 `PRD.md` 第 9 节。
